# Team Grid icon sources

The Team Grid ships only the individual SVG files listed below. Profile data stores a whitelisted key, never SVG markup. The files are rendered locally; there is no CDN, icon font, JavaScript, or runtime network dependency.

## Brand icons

The `instagram`, `github`, `mastodon`, `bluesky`, `facebook`, `youtube`, `tiktok`, and `x` shapes were copied without shape changes from the official [Simple Icons repository](https://github.com/simple-icons/simple-icons) at commit `070d5d580aacde3badabf0dd25cb8e818490f7a1`.

Simple Icons is published under [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md), which does not require attribution. Its [legal disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md) states that CC0 does not waive third-party trademark or other brand rights. At the recorded commit, Simple Icons' metadata declares no separate per-icon license for these eight icons and links to each brand's source or brand guidelines. Consumers remain responsible for using brand marks consistently with the applicable brand rules.

Simple Icons no longer contains a LinkedIn SVG at the recorded commit. The local `linkedin` icon therefore uses only the individual `brand-linkedin.svg` from Tabler Icons.
